## 1. 기능 목록

| ID | 기능 | 화면 | 요약 |
|---|---|---|---|
| F-01 | 위치 권한 안내 | 1g `/welcome` | 첫 방문 시 위치 사용 목적을 안내하고 권한을 요청 |
| F-02 | 현재 위치 날씨 | 1c `/` | GPS 위치의 현재 기온·하늘 상태·최고/최저, 어제 같은 시각과의 차이 |
| F-03 | 오늘 vs 어제 막대 비교 | 1c `/` | 3시간 간격 8개 시각의 어제·오늘 기온을 나란한 막대로 표시 |
| F-04 | 시간대별 상세 비교 | 1d `/detail` | 0~23시 24행 표 + 어제·오늘 꺾은선 그래프 |
| F-05 | 지역 검색 | 1f `/search` | 시·구·동 이름으로 지역을 찾고 현재 기온·어제 대비 차이를 미리 보기 |
| F-06 | 즐겨찾기 | 1e `/favorites` | 지역 추가·해제, 순서 변경, 삭제. 카드마다 어제 대비 차이 표시 |
| F-07 | 최근 검색어 | 1f `/search` | 최근 검색어 5개를 칩으로 보관 |
| F-08 | 데이터 갱신 | 1c `/` | 당겨서 새로고침, 앱 복귀 시 자동 갱신, 자정 지나면 자동 갱신 |
| F-09 | 홈 화면 추가 (PWA) | 전체 | 앱처럼 설치해 주소창 없이 실행 |
| F-10 | 위치 정보 보호 | 전체 | 서버로 보내는 좌표를 약 100m 단위로 반올림, URL에 현재 위치 좌표를 넣지 않음 |

화면 번호(1c~1g)는 디자인 시안 번호와 같다. 디자인 시안 중 1a·1b는 채택하지 않아 구현하지 않았다.

## 2. 화면 흐름

```
첫 방문 ──▶ /  ──권한 상태 확인──┬─ 허용됨 ─────────────▶ 1c 메인 (GPS)
                                ├─ 아직 안 물어봄 ──────▶ 1g 안내 ──[현재 위치 사용]──▶ 1c
                                │                              └─[지역 직접 검색]──▶ 1f
                                └─ 거부됨 ─┬─ 즐겨찾기 있음 ─▶ 첫 즐겨찾기 지역의 1c
                                           └─ 없음 ─────────▶ 1f (권한 안내 문구 표시)

1c ──막대 그래프 / "시간대별로 자세히 보기"──▶ 1d
1e·1f 의 지역 카드/행 ──▶ 그 지역의 1c (/?lat=…&lon=…&name=…)
하단 탭바: 현재 위치(/) · 즐겨찾기(/favorites) · 검색(/search)
```

- 권한 상태는 브라우저 Permissions API로 확인한다. 이 API가 없는 브라우저는 "아직 안 물어봄"으로 취급한다.
- 1g를 한 번 거치면 `onboarded` 값을 저장해 다시 보여주지 않는다.
- 즐겨찾기·검색에서 고른 지역은 URL 쿼리(`lat`, `lon`, `name`, `label`, `sub`)로 전달한다. 즐겨찾기에 없는 지역도 링크로 열 수 있다.

## 3. 화면별 기능 상세

### 3.1 1g 위치 권한 안내 (`/welcome`)
| 요소 | 동작 |
|---|---|
| 안내 문구 | "현재 위치의 어제·오늘 기온을 시간대별로 비교합니다" + 권한 사용 목적 설명 |
| [현재 위치 사용] | 브라우저 위치 권한 팝업을 띄우고, 성공하면 1c로 이동. 실패·거부 시 1f(권한 안내 문구 포함)로 이동 |
| [지역 직접 검색] | 1f로 이동 |

### 3.2 1c 메인 (`/`, `/?lat&lon&name&label&sub`)
| 요소 | 동작 |
|---|---|
| 지역 이름 | GPS 모드면 위치 아이콘 + 동 이름(예: 포일동). 지정 지역이면 그 지역 이름 |
| ☆ 즐겨찾기 | 지금 보고 있는 지역을 즐겨찾기에 추가/해제 |
| 현재 기온 | 지금 시각(정시 내림)의 오늘 기온 |
| 하늘 상태·최고/최저 | 지금 시각의 하늘 상태와 아이콘, 오늘 24시간 최고/최저 |
| 비교 배지 | `어제보다 N° 높음` / `어제보다 N° 낮음` / `어제와 같음` + `어제 N°` |
| 오늘 vs 어제 막대 | 0·3·6·…·21시 8쌍. 각 열 위에 차이(+3°)와 오늘 기온. 지금 시각이 속한 3시간 구간은 진한 주황 + "지금" |
| 요약 문장 | `최고 기온 어제 N° → 오늘 N° · 최저 기온 어제 N° → 오늘 N°` |
| 막대 그래프 탭 | 1d 상세로 이동 |
| 당겨서 새로고침 | 시트 맨 위에서 아래로 당기면 날씨와 GPS 위치를 다시 받음 |
| 로딩·오류 | 기온·막대 자리에 스켈레톤. 오류 시 [다시 시도] 버튼 |
| 출처 표기 | "데이터 Open-Meteo · 어제 값은 모델 분석값, 오늘 값은 예보" |

### 3.3 1d 시간대별 상세 (`/detail`)
| 요소 | 동작 |
|---|---|
| 헤더 | `‹` 뒤로, 제목, `{지역} · MM/DD vs MM/DD` |
| 꺾은선 그래프 | 오늘 실선(주황), 어제 점선(회청색), 지금 시각 세로 점선 |
| 24행 표 | 시간 / 어제 기온·하늘 / 오늘 기온·하늘 / 차이 막대·수치 |
| 지금 행 | "지금" 굵게, 배경 강조. 진입 시 화면 가운데로 자동 스크롤 |
| 현재 위치 | URL에 좌표 없이 `/detail` 로 열고 마지막 GPS 위치를 사용. 위치 정보가 없으면 안내 + [메인으로] |

### 3.4 1f 지역 검색·추가 (`/search`)
| 요소 | 동작 |
|---|---|
| 검색창 | 16px 글자(아이폰 확대 방지), 포커스 시 테두리 |
| 검색 시점 | Kakao 키가 있으면 입력 후 300ms 뒤 자동 검색. 없으면(Nominatim) **키보드 검색 버튼(엔터)** 을 눌렀을 때만 검색 — 서비스 이용 정책 때문 |
| 결과 행 | 지역명 / `{상위 행정구역} · 현재 기온 · 어제보다 ±N°` |
| [+ 추가] ↔ [★ 추가됨] | 즐겨찾기 토글 |
| 결과 행 탭 | 그 지역의 1c로 이동 |
| 최근 검색 | 결과가 있었던 검색어 최대 5개. 탭하면 다시 검색 |
| 상태 문구 | 찾는 중 / 결과 없음 / 오류 + [다시 시도] / 위치 권한 거부 안내 |
| [취소] | 입력이 있으면 지우기, 없으면 이전 화면 |

### 3.5 1e 즐겨찾기 (`/favorites`)
| 요소 | 동작 |
|---|---|
| 첫 카드 | **현재 위치**(검은 카드). 마지막으로 잡은 GPS 위치를 표시하고, 권한이 이미 허용돼 있으면 조용히 새로 고침 |
| 즐겨찾기 카드 | 지역명, `하늘 · 최고/최저`, 현재 기온, 비교 칩(증감 색 배경) |
| ★ 별 | 즐겨찾기 해제/재추가. 해제해도 화면을 떠나기 전까지 카드가 남아 되돌릴 수 있음 |
| [편집] | ▲▼ 순서 변경, 🗑 삭제. [완료]로 종료 |
| 카드 탭 | 그 지역의 1c로 이동 |
| 빈 상태 | "아직 즐겨찾기한 지역이 없어요" + [지역 검색] |

## 4. 비교 규칙

| 항목 | 규칙 |
|---|---|
| 차이 계산 | `차이 = 반올림(오늘 기온) − 반올림(어제 기온)` — 정수 °C |
| 수치 표기 | `+3°`, `−2°`(유니코드 마이너스 U+2212), 0이면 `같음` |
| 문장 표기 | `어제보다 3° 높음` / `어제보다 2° 낮음` / `어제와 같음` |
| 색 | 높음 주황 `oklch(0.58 0.15 45)`, 낮음 파랑 `oklch(0.55 0.12 250)`, 같음 회색 |
| 기준 시각 | 그 지역 현지 시각의 정시 내림 (예: 14:20 → 14시) |
| 최고/최저 | 그날 0~23시 기온을 각각 반올림한 뒤의 최댓값/최솟값 |
| 막대 높이 | 화면에 나오는 8개 시각의 어제·오늘 기온을 합친 범위를 14~126px로 선형 변환. 범위가 8°보다 좁으면 8°로 넓혀 작은 차이가 과장되지 않게 함 (디자인 시안의 `(기온−4)×7` 공식은 영하·폭염에서 깨져 대체) |
| 꺾은선 그래프 | 어제·오늘 48개 값 범위로 세로축을 정규화 |
| 자정 처리 | 받아 둔 자료의 "오늘" 날짜가 지났으면 자동으로 다시 받음 |

### 하늘 상태 (WMO weather code → 한글)
| 코드 | 표시 | 아이콘 |
|---|---|---|
| 0 | 맑음 | 해 (밤에는 달) |
| 1 | 구름조금 | 해+구름 (밤에는 달+구름) |
| 2 | 구름많음 | 해+구름 (밤에는 달+구름) |
| 3 | 흐림 | 구름 |
| 45, 48 | 안개 | 안개 |
| 51~57 | 이슬비 | 이슬비 |
| 61~67 | 비 | 비 |
| 71~77, 85~86 | 눈 | 눈 |
| 80~82 | 소나기 | 비 |
| 95 이상 | 뇌우 | 번개 |

낮·밤은 Open-Meteo의 `is_day` 값으로 판단한다.

## 5. 데이터 갱신·캐시

| 위치 | 방식 | 유지 시간 |
|---|---|---|
| 서버 – 날씨 | 지점(약 1km 격자) + 서울 날짜 단위로 캐시 | 15분마다 갱신, 최대 1시간 |
| 서버 – 지역 검색·동 이름 | 검색어 / 좌표(약 100m 격자) 단위로 캐시 | 하루 |
| 폰 – 날씨 | 메모리 캐시. 화면을 오가도 다시 받지 않음 | 10분 |
| 폰 – 자동 갱신 | 앱으로 돌아올 때(화면 보임), 당겨서 새로고침, 자정 경과 | — |

## 6. 폰에 저장하는 정보 (localStorage)

| 키 | 내용 | 비고 |
|---|---|---|
| `favorites` | 즐겨찾기 지역 목록 (이름, 좌표) | 좌표는 약 100m 단위 |
| `recentSearches` | 최근 검색어 최대 5개 | |
| `onboarded` | 1g 안내를 봤는지 | |
| `lastGps` | 마지막으로 잡은 현재 위치(동 이름, 좌표) | 다음 실행 때 먼저 보여 주는 용도. 좌표는 약 100m 단위 |

- 모든 값은 **그 폰의 브라우저 안에만** 있고 서버로 보내지 않는다. 다른 사용자와 공유되지 않는다.
- 브라우저 데이터를 지우면 즐겨찾기도 사라진다(로그인·동기화 없음).
- 저장소를 쓸 수 없는 환경(사생활 보호 모드 등)에서도 오류 없이 동작하고, 저장만 되지 않는다.

## 7. 위치 정보 보호

| 항목 | 처리 |
|---|---|
| 사용하는 권한 | 위치 하나뿐. 연락처·사진·파일 등은 웹 브라우저 구조상 접근할 수 없음 |
| 서버로 보내는 좌표 | GPS 값을 폰에서 **소수 셋째 자리(약 100m)로 반올림**한 뒤 전송 |
| 외부 서비스로 보내는 좌표 | 날씨는 약 1km, 동 이름은 약 100m 단위. 외부 서비스에는 사용자 IP가 아니라 우리 서버가 요청 |
| URL | 현재 위치는 URL에 좌표를 넣지 않음(`/detail`). 공유 링크로 위치가 새지 않음 |
| 개인 식별 정보 | 회원가입·로그인·이름·연락처 수집 없음. 광고·추적 도구 없음 |
| 이전 버전 데이터 | 앱 실행 시 저장돼 있던 정밀 좌표를 자동으로 반올림 |

## 8. 알려진 제한

| 항목 | 내용 | 개선 방법 |
|---|---|---|
| 어제 기온의 정확도 | Open-Meteo의 어제 값은 관측소 실측이 아닌 모델 분석값이라 실제와 1~2° 다를 수 있음 | 기상청 ASOS 관측값으로 전환 ([서비스명세서](서비스명세서.md) 6장) |
| 지역 검색 품질 | Kakao 키가 없으면 Nominatim을 써서 동 단위 검색이 약하고 자동 검색이 안 됨. "강릉"처럼 접미사 없이 검색하면 "강릉시"도 함께 찾도록 보완 | `KAKAO_REST_API_KEY` 설정 |
| 검색 범위 | 국내(KR) 지역만 검색 | — |
| Kakao 연동 | 코드는 있으나 키가 없어 실제로 검증하지 않음 | 키 발급 후 검증 |
| 오프라인 | 서비스 워커가 없어 인터넷이 없으면 동작하지 않음 | 필요 시 추가 |
| 즐겨찾기 동기화 | 기기 간 동기화 없음 | 로그인·DB 추가 시 가능 |
| 서버 캐시 | Vercel 서버 메모리 캐시라 서버가 재시작되면 비워짐(다시 받으면 됨) | 필요 시 외부 캐시 저장소 |
